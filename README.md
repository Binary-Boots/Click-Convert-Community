## 📖 About Click Convert

**Click Convert** is a fast, private, and native macOS app that turns everyday PDF and image tasks into a single click. Convert, split, merge, compress, and make your documents searchable — right from the app window or **directly in Finder** with a right-click. No uploads, no accounts, no waiting: everything happens locally on your Mac.

Whether you're preparing documents for email, digitizing scans, or wrangling a pile of photos into a single PDF, Click Convert gets it done in seconds.

---

## ✨ Core Features

### 📄 PDF Tools
- **PDF → PNG / JPEG** — Convert every page to high-quality images at your chosen DPI.
- **Split PDF** — Break a multi-page PDF into individual single-page files.
- **Merge PDFs** — Combine multiple PDFs into one document.
- **Compress PDF** — Shrink file size with ready-made presets:
  - 📧 **Compress for Email** (~96 DPI)
  - ⚖️ **Balanced** (~120 DPI)
  - 🗜️ **Maximum Compression** (~72 DPI)
  - 🔤 **Preserve Text** (lossless re-save)
- **Make Searchable (OCR)** — Add a searchable, selectable text layer to scanned PDFs and images using on-device recognition — with support for **English, French, German, Spanish, Italian, Portuguese, Chinese (Simplified & Traditional), Japanese, Korean, and Arabic**.
- **Organize Pages** — Reorder, rotate, and delete pages visually.

### 🖼️ Image Tools
- **HEIC → JPEG / PNG** — Convert iPhone photos to universally compatible formats.
- **Images → PDF** — Bundle multiple images into a single PDF document.

### ⚡ Productivity
- **🖱️ Finder Extension** — Right-click any PDF or image in Finder and convert instantly, no need to open the app.
- **🧩 Recipes** — Save your favorite conversion settings and run them in one click.
- **👀 Watch Folders** — Automatically apply a recipe to any file dropped into a folder.
- **☁️ Cloud-Aware** — Smart detection for iCloud Drive and other cloud files, prompting you to download before converting.

### 🛡️ Privacy & Native Experience
- **100% On-Device** — Your files never leave your Mac. No cloud, no tracking, no accounts.
- **Native macOS** — Built with SwiftUI and Apple's frameworks for a fast, lightweight, energy-efficient experience.
- **♿ Accessibility First** — Scalable fonts, high-contrast colors, and dark mode support.
- **🌍 45 Languages** — Fully localized interface for a global audience.
